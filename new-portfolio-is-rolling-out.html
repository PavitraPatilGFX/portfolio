🚀 Portfolio Update – Plastic UI (Release v1)

A fresh new look, better performance, and exciting features!
This update introduces a sleek UI upgrade, a brand-new blog section, social media integration, and major optimizations for a smoother experience.

✨ UI Enhancements

  • Introduced Chahk as the homepage highlight for a striking first impression.
  • Added icon support to enhance visual appeal and accessibility.
  • Upgraded portfolio typography to Maven Pro for a sleek, modern aesthetic.
  • Improved overall color scheme for better contrast and readability.

⚡ Performance & Optimization

  • Migrated to Static Site Generation (SSG) for faster load times and improved performance.
  • Implemented dynamic image handling for optimized media delivery.
  • Enabled lazy image loading to enhance page speed and efficiency.

📂 Repository Overhaul

  • Reorganized folder and file structure for better maintainability and scalability.

🆕 New Features

  • Blog Section is now live – explore, read, and share insights!
  • Integrated social media icons and links, starting with Instagram.

❌ Deprecated Features

  • Removed OLED, Light, and Dark themes due to technical constraints.
  • Discontinued the website startup loading screen to streamline the user experience.
